then develop and hand over the product

Which menu do I open, what do I enter, and when do I move on?
Follow vehicle registration and the seven development stages for Seat Cover, Floor Mat, and Car Cover.

Vehicle registration→Options / Configuration→Research complete→Create project→Develop by product→Handoff
Read from the startSeat CoverFloor MatCar Cover

How to use this guide

  1. Read A1–A5 first to learn vehicle, option, and project creation.
  2. Then choose one product and follow stages 1–7. You do not need to create all three products.
  3. At each stage, checkInputs → Screen → Completion criteria. Click screenshots to enlarge.
  4. For stage 5, also read theshared inspection exercise. If stuck, review theimplementation limitsbefore continuing.
Separate training examples from actual workArchived screenshots were captured in a separate browser without changing production data. A1–A5 show manually created examples; product stages use prepared sample states for existing example vehicles. They are not proof of a successful end-to-end save through every step. Do not use TEST/GUIDE records, fictional schedules, paths, or DXFs for actual production or approval. Opening this guide does not enter data into the app.

A1
Vehicle Research → Register vehicle

Register the vehicle first

A vehicle is the first record identifying the car. This does not yet create a product or Shape.

Follow these steps

  1. Open Vehicle Research under R&D Tools on the left.
  2. Click Register vehicle on the right. Enter make, class, model, and model years.
  3. Submit the dialog and find Toyota RAV4 GUIDE in the list.

A2
Vehicle Options

Think of options as questions and answers

An option key is a question (front seat type?); its value is an answer (Bucket). Reuse existing values rather than duplicating them.

Follow these steps

  1. Check the product type in Vehicle Options first. Seat Cover, Floor Mat, and Car Cover use separate option dictionaries.
  2. Skip creation if the required keys and values already exist.
  3. Add only missing keys using Add option key → Enter name → Create.
  4. Use Add value under that key to enter available choices.

A3
Vehicle Research → + Configuration beside the vehicle

Define the option combination to develop

A configuration means this vehicle with these specifications. The same RAV4 needs separate combinations for different front or rear seats.

Follow these steps

  1. Click Configuration beside Toyota RAV4 GUIDE.
  2. Choose the question (criterion) on the left and answer (value) on the right.
  3. Select Hybrid / Bucket / Bench as shown. Add another criterion if needed.
  4. Verify actual specifications and register the configuration.
  5. Read the option chips and distinguish the default 7 Seats / Captain row from the new Bench row.

A4
Vehicle Research → Research Complete

Confirm research completion

Entering a vehicle name and completing enough research to develop it are different.

Follow these steps

  1. Compare vehicle name, model years, and options against research evidence or the actual vehicle.
  2. For RESEARCHING rows, click Research Complete after finishing research. Do not repeat this for COMPLETE rows.
  3. Choose Start Development on the intended row or New Project in Vehicle Projects.
  4. This exercise uses the newly created Hybrid / Bucket / Bench combination.

A5
Vehicle Projects → New Project

Choose a product type and create a project

A project groups the work of developing a particular product for a particular vehicle configuration.

Follow these steps

  1. Click New Project, select Seat Cover in Step 1, and continue.
  2. In Step 2, select Toyota RAV4 GUIDE with Hybrid / Bucket / Bench, then continue.
  3. In Step 3, check assignee Kai and development zones. This example creates F and B.
  4. In Step 4, recheck the vehicle, options, product type, and assignee.
  5. Click Create Project Group and note the actual generated number.

Seat Cover · 2023–2026 Toyota RAV4 · PG-00124-F → Visits

6. Fitting — Test on the actual vehicle

A sample matching the drawing still needs a separate test on the actual vehicle.

Follow these steps

  1. Resolve incomplete Sample requirements first.
  2. In Visits → Schedule Visit, select Fitting. Verify vehicle, date, zones, and staff.
  3. Install the sample and check interference, fastening, lifting, and gaps. Record photos and results.
  4. Complete the visit with PASS or FAIL based on actual results.
  5. If FAIL, return to Pattern/Design and repeat: Revised version → New sample → Reinspection → Refitting.

7. Handoff — Deliver materials to production

The final step organizes materials so production can continue with another owner.

Follow these steps

  1. When sample/fitting conditions are satisfied, open Record handoff completion in Overview. Legacy completed data may show Record handoff verification.
  2. Record locations for the final parts list, blueprint, fitting photos/videos, product photos, manual, and design files.
  3. Check only materials you have opened and reviewed. Also verify vehicle, options, zone, and project number.
  4. Select the handoff approver and confirm actual delivery and approval before checking the box.
  5. Save Handoff complete / Development complete only when errors are resolved and requirements met. The warning example below is not a completed handoff.
